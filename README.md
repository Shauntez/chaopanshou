# 超级操盘手 · 账号定位与内容生产技能包

一套给 AI 用的技能包。你把「我是谁、我做过什么」告诉 AI，它会带你从零走完：深访建档 → 对标拆解 → 定位报告 → 每日选题 → 口播稿 → 评论/私信话术 → 矩阵分工 → 发布后复盘。

## 它解决什么问题

多数人做账号卡在第一步——不知道该拍什么。这个技能包不让 AI 直接给你一堆泛泛建议，而是先问清你是谁、你手上的真东西是什么、你想靠账号换什么，再往下推。技能包里写死了开场流程、追问颗粒度、信息增量闸门和禁用口径，避免跑偏。

## 文件结构

```
SKILL.md                  主流程（开场四步、对话纪律、阶段推进、交付规则）
references/
  interview.md            深访：四组话题、叙事优先、追问句库
  profile-card.md         六维画像卡模板
  benchmark.md            对标检索、五维拆解、硬标准
  positioning.md          定位报告结构、一句话定位公式
  script.md               单条口播稿五段结构与自检
  calendar.md             周/月选题日历
  conversion.md           评论区与私信转化话术
  matrix.md               多人矩阵分工
```

## 安装

方式一，直接跟 AI 说：

> 请帮我安装技能包「超级操盘手」：打开 https://github.com/Shauntez/chaopanshou ，把 SKILL.md 和 references/ 下全部 md 文件下载下来，放到你的技能目录 `.skills/chaopanshou/`，SKILL.md 放根目录，references 放子目录，装好后告诉我。

方式二，命令行：

```bash
git clone https://github.com/Shauntez/chaopanshou.git
# 把整个目录放进你的技能目录，重命名为 chaopanshou
```

## 怎么用

装好之后，你只要说一句：我是做什么的、我想做什么账号。剩下的引导、提问、落档、出稿由技能包接管。

## 说明

技能包内不含任何真实人物信息、公司名或战绩数据，所有示例均为占位。用户资料只落在用户自己的目录，不回写进技能包。
