# 账号画像卡（六维）

> 一个账号一份文件：`账号画像_<称呼>.md`。它是这个账号的**唯一事实源**，所有环节开跑前先读它。
> 没有画像也能工作，画像只是让产出更准。

## 一、六维结构

| 维度 | 回答什么问题 | 哪个环节用 |
|---|---|---|
| ① 定位 | 我是谁、凭什么是我、往哪个方向做 | 选题、报告 |
| ② 风格 | 我怎么说话：语气、开头方式、节奏、出镜形式 | 出稿 |
| ③ 受众 | 说给谁听：人群、所处状态、痛点原话 | 选题、出稿 |
| ④ 平台 | 发在哪：账号现状、内容形式、平台规则 | 发布与适配 |
| ⑤ 红线 | 什么不能碰：不做的人群、不承诺的结果、合规底线 | **全流程强制** |
| ⑥ 长期记忆 | 学到什么：跑通的公式、踩过的坑、数据结论 | 出稿、复盘 |

## 二、模板（复制即用，全部方括号待填）

```markdown
# 账号画像 · [称呼]

> 建档日期：[YYYY-MM-DD] ｜ 最后更新：[YYYY-MM-DD] ｜ 完整度：[x/6]

## ① 定位
- 一句话： [他做什么、为谁做、凭什么被信]
- 差异化壁垒： [别人抄不走的那一条，要具体经历或能力，不要形容词]
- 内容主线（1–3 条）： [案例复盘 / 方法干货 / 观点人设 / 机会解读]
- 当前阶段： [从 0 起号 / 已有号待调整 / 已有号放量]

## ② 风格
- 语气： [犀利 / 克制 / 亲和 / 老师型]
- 开头方式： [冲突式 / 提问式 / 结论前置 / 场景切入]
- 节奏： [短平快 / 慢讲透]
- 出镜形式： [口播 / 访谈 / 纪实 / 混合]
- 标志性元素： [口头习惯、固定开场、固定道具]

## ③ 受众
- 核心人群： [行业 / 规模 / 身份]
- 所处状态： [正在经历什么]
- 痛点原话： [客户自己说过的一句话，原话照抄]
- 次要人群： [合作方、企业客户等]
- 不要的人群： [明确不接的]

## ④ 平台
- 主平台： [名称 + 账号状态]
- 内容形式：[竖屏口播 / 图文 / 长视频]
- 平台规则要点：[时长、字数、标签、审核敏感点]

## ⑤ 红线
- 不做的内容： [ ]
- 不接的人群： [ ]
- 不用的身份： [用户明确不想再用的头衔/身份，不得作为主线或切入点]
- 不承诺的结果： [不涨粉、不保证成交、不保证收入]
- 合规： [不写未开展的业务；不用绝对化用语]

## ⑥ 长期记忆
- 跑通的公式： [结构 / 开头 / 选题类型 + 数据表现]
- 踩过的坑： [哪类选题无效、哪个说法被误解]
- 受众反馈： [评论区反复出现的问题]
- 复盘结论： [日期 + 一条结论]
```

## 三、填写规则

1. **只写确认过的**。他说的原话进引号，你没听清的标【待填】，绝不推测。
2. **数字要具体**。“十几年”要落成“约十几年，从 [年份] 起”；价格写数字不写“差不多”。
3. **差异化壁垒必须可验证**。写成“有 3 年 X 行业交付经验、做过 N 个客户”比“经验丰富”有用一百倍。
4. **红线是硬规则**，写进去的东西后续任何环节都不能违反；红线为空也算一种状态，要显式写“暂未确认”。
5. **长期记忆只记可复用的认知**，不记流水账；“这条稿播放 2000”不算认知，“反常识开头在本地生活类里有效”才算。
6. **称呼只用当轮给的，不猜不记**：文件名一律 `账号画像_<代称>.md`、`定位报告_<代称>.md`。代称只用用户本轮自己给的；没给就用中性词（如“账号主理人”）。**禁止从记忆、历史对话、旧档案里取姓名或昵称，也不把用户身份写进长期记忆。**
7. **禁用身份单列**：用户明确说“不想再用某个身份”时，写进⑤“不用的身份”，后续所有选题与稿件都不得以它作主线或标题切入点。

## 四、更新规则

- 用户当轮说法与画像冲突 → 以当轮为准，落档后提示“画像第 X 段已过期，要不要更新”。
- 每次复盘必须写一条进 ⑥；没有新认知就写“本次无新结论”，不留空。
- 每次更新改顶部“最后更新”与“完整度”。
