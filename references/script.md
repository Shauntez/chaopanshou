# 单条口播稿模板

> 默认轻量可拍稿。用户明确要镜头表/分镜时，再升级为镜头拆解。

## 〇、先过"信息增量闸门"（不过就别写）

写之前先用一句话回答：**这条比同类内容多给了什么？**

可能是：一个真实案例、一组数字、一个别人没提的坑、一个更清楚的步骤、一个更硬的观点。

**写不出这句话，就不要写**——它会成为同类的第十一个副本，平台和用户都没有理由选它。这时应该回去换选题，而不是硬写。

## 一、稿前先定五项

- 选题与所属主线（案例复盘 / 方法干货 / 观点人设 / 机会解读）
- 平台、目标时长、出镜形式（取自画像卡 ② ④）
- 目标人群与核心痛点（取自画像卡 ③）
- 转化目标：私信 / 进活动 / 咨询 / 加微信（关注与评论算顺带）
- 他能提供的真实素材：案例、数字、客户原话

**素材不足时**：直接说"这条目前只有观点没有案例，先拍观点版；有真实案例了再拍案例版"，不用编造补足。

## 二、标题备选 2–3 个

- 前置冲突或反常识，口语化，不超过 20 字
- 每个标题对应不同钩子角度，便于 A/B
- 不用"震惊""必看""干货满满"这类无效词

## 三、五段结构（约 60 秒基准，按平台调整）

1. **钩子（0–5s）**：冲突、痛点、反常识设问或一个具体动作。第一句就得给出继续看的理由。
2. **痛点共鸣（5–18s）**：把他目标人群的卡点说到能对号入座，用具体场景不用抽象词。
3. **核心观点/方法（18–40s）**：给判断或步骤，必须挂在他自己的真实经历或壁垒上（画像卡 ①）。观点要有依据，不喊口号。
4. **态度落点（40–52s）**：收成一句能记住的话。这句是全稿最该打磨的一句。
5. **行动引导（52–60s）**：只给一个动作，语气自然，不硬推。

每段标注：画面建议 / 台词 / 花字要点。

## 四、交稿前五问自检

1. **钩子够硬吗**：前 3 秒有没有让人停下的理由
2. **结构有起伏吗**：是不是平铺直叙，有没有转折
3. **有水分吗**：哪句话删掉不影响理解，就删
4. **引导具体吗**：他要做什么动作，说清了没有
5. **像他吗**：换个人名还能成立，说明没写进他的人设，要改

五问里有两问不过，自己先改一遍再交，不要把半成品丢给用户。

## 五、评论预埋与回复口径

- 置顶预埋一个问题，降低开口门槛（问行业、问状态，不问"你觉得呢"）
- 高频问题按 `conversion.md` 的分类准备标准回复
- 涉及产品、价格一律以画像卡为准；没确认的先反问，不承诺

## 六、拍摄与剪辑提示

- 场景、光线、机位；固定口播与空镜穿插的节奏
- 花字只打关键句，字号大、对比强
- 合规：不承诺收入与涨粉；数据有真实结果再上
- 备用镜头：工作现场、客户交流、过程空镜

## 七、归档

- 存为 `脚本<序号>_<选题关键词>.md`
- 选题与状态回写画像卡 ⑥ 与选题台账；发布后回填数据做复盘
