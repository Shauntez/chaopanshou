# 对标检索与拆解

> 目的：在出定位报告之前，**真的上网搜**可对标账号，拆成表，再给判断。不是凭印象报名字。
> 拆对标不是罗列数据，是回答三个问题：**什么内容会爆、多久发一次、靠什么涨粉。**

## 一、检索前先定三个词

从画像卡 ① 定位 和 ③ 受众 里取词，组成检索串：

```
[行业/领域] + [他做的事] + [账号/博主/IP]
[人群] + [痛点词] + [短视频/口播]
```

**必须真搜**：至少 3 组检索词、覆盖 2 个平台（抖音/小红书/视频号/B站/公众号），记下账号名、主页、代表作。搜不到就明说搜不到，不许编账号。

## 二、三类对标，各学一样

| 类型 | 找什么样的 | 学什么 | 不学什么 |
|---|---|---|---|
| **主对标** | 身份、路径最像的（同行业/同出身/同变现） | 定位怎么切、人设怎么立、主线怎么排 | 他的具体产品与价格 |
| **辅对标** | 打法可迁移的（跨行业但结构同） | 选题结构、开头钩子、评论区承接 | 他的行业结论 |
| **氛围对标** | 表达气质接近的 | 语气、节奏、镜头感 | 他的观点立场 |

每类 1–3 个，宁少不滥。

## 三、先定"爆款"再谈爆款

- **别只看绝对点赞数**，会被粉丝基数骗。
- 判定标准：单篇互动量 ≥ 该账号近期**中位数的 3–5 倍**才算爆。
- 不同量级横向比，用**互动率（互动量/粉丝量）**，不用绝对值。

## 四、拆解维度（每个候选都要过一遍）

| 维度 | 看什么 |
|---|---|
| 选题 | 常青刚需 / 热点借势 / 个人故事，爆款集中在哪一类 |
| 标题钩子 | 数字化、悬念、痛点、反常识、身份认同——用了哪几种 |
| 封面与开头 | 大字报/实拍/对比图/人脸；前 3 秒怎么留人 |
| 结构节奏 | 清单体、故事体、教程步骤、反转；信息密度与停顿 |
| 结尾引导 | 提问 / 求收藏 / 埋钩子引下一条 |
| 互动结构 | 收藏高＝工具向；转发高＝情绪向。比例说明定位 |
| 产品组合 | 前端引流是什么、主利润是什么、后端是什么、价格带 |
| 变现入口 | 私信 / 主页 / 评论区 / 直播 / 挂车，成交在哪一步发生 |
| 评论区缺口 | 反复被问但没人答的问题；被吐槽的点 |

**从爆款反推密码**：把该账号所有爆款横着对齐，找共性——同一类选题反复爆？同一种封面模板？同一个情绪按钮？共性＝可复用公式；只爆过一次的（蹭大热点）单独标注，不算稳定打法。

## 五、更新节奏（决定你能不能跟）

| 指标 | 怎么算 | 说明什么 |
|---|---|---|
| 发布频率 | 近 30 天篇数／30 | 日更 / 隔天 / 周更 / 佛系 |
| 节奏规律 | 发布日期分布 | 固定周几、固定时段，还是随缘 |
| 稳定性 | 篇数的周波动 | 稳定输出 vs 爆发式断更 |
| 系列化 | 有无固定栏目/合集 | 有没有养成追更习惯 |

判读：高频稳定＝吃平台权重但吃库存；低频高质＝靠单篇拉新。看清他走哪条，再定你跟不跟。

## 六、涨粉引擎推断（拿不到精确增量，就用公开信号推）

| 看到的现象 | 推断的增长引擎 |
|---|---|
| 爆款评论里大量"刚关注/被推来的" | 单篇爆款拉新 |
| 粉丝量远高于篇均互动 | 早期红利或搬运引流，活跃度在掉 |
| 篇均互动稳定爬升、发布规律 | 稳定运营滚雪球 |
| 互动集中在少数系列或人设梗 | IP／人设驱动 |
| 频繁出现在热搜话题下 | 借势驱动 |
| 评论区大量"从 X 平台过来" | 跨平台导流 |

关键判断：他靠**单点爆款**还是**持续输出**？前者天花板高但不稳，后者慢但扎实。这决定你是跟他拼爆款，还是拼稳定度。

## 七、输出：一句话打法总结

每个入选账号必须沉淀成一句话，例如：
"靠固定『X 对比』选题模板＋大字报封面稳定周更，涨粉主要来自评论区追问带来的系列追更。"

先给结论，再挂证据，不许只甩数据。

## 八、反馈与二次检索（重要）

候选给出去后，用户可能提想法，也可能不提。**不提就直接进下一步，不要反复推销。**

| 他的反馈 | 你要做的 |
|---|---|
| "这个不像我" | 问清哪不像（人设/人群/变现），换检索词**重搜一轮** |
| "我想做成那样" | 把他指的账号再往下拆一层：近 10 条的选题分布、开头句式、更新节奏 |
| "还有没有别的" | 换角度补 3–5 个：更垂直的、更草根的、变现更轻的、同城同行业的 |
| "这个我不想碰" | 记进画像卡 ⑤ 红线，后续不再推同类 |

**二次检索必须真搜**，不能把上一轮结果换个说法再念一遍；要说明"这次换了哪几个词、为什么换"。

## 九、三条硬标准（筛掉不合格候选）

1. **活着**：近 3 个月还在更新，不是停更号
2. **同路径**：变现方式能对应用户画像里的产品层级（不能拿纯带货号当卖课对标）
3. **可拆**：主页能看出选题规律，不是靠一条爆款撑着

## 十、交付格式

先给一张总表（账号 / 平台 / 量级 / 一句话打法 / 学什么），再给重点 2–3 个的完整拆解，最后一段"所以我们的差异点在哪"。**不堆名单，每个入选的都要说清凭什么。**
