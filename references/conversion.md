# 评论区与私信转化口径

> 所有口径以画像卡 ③（人群）与 ⑤（红线）为准。产品、价格、边界未确认时一律反问，不承诺。

## 一、高频问题分类与应对

| 类型 | 典型问题 | 应对口径 |
|---|---|---|
| 求方向 | 我啥也不会 / 不知道能干啥 | 先问行业、做过什么、手上有啥资源，再判断能不能变现 |
| 求方法 | 用什么工具 / 怎么学 | 不堆工具清单；先讲定位和业务，工具按落地环节给 |
| 求带 | 能不能带我 / 怎么加入 | 先私信了解背景与诉求，再匹配层级；不硬推 |
| 问价格 | 你这个多少钱 / 包含什么 | 按画像卡产品分层回答；定制类说明需按需求评估 |
| 质疑 | 又是割韭菜 / 卖课的吧 | 不争辩；说清业务边界，用真实案例说话；没有案例就不举 |
| 认同 | 说得对 / 我也是这样 | 置顶互动，引导补充自身情况，沉线索 |

## 二、私信承接四步

1. **先问背景**：行业、做过什么、现在想解决什么。不报价。
2. **匹配层级**：按诉求对应到画像卡里的某个产品层级。
3. **给下一步**：明确一个动作（约聊、进活动、发资料），话术自然。
4. **记录归档**：线索来源、诉求、承接产品回写台账，便于复盘。

## 三、口径红线

- 不承诺“一定赚钱 / 一定起量 / 保证效果”
- 不编造学员数量、收入案例、合作背书
- 未开展的业务不写成在售
- 医疗、投资、法律等专业领域只做经验分享，不替代专业建议
- 不用绝对化用语（最好、第一、唯一）

## 四、话术骨架（方括号全部待填，禁止照抄示例）

- **评论引导**：你现在是卡在 [方向类问题]，还是 [执行类问题]？评论区说下你的 [行业/身份]，我挑几个回。
- **私信开场**：你好，先简单说下你现在做什么、之前有哪些积累，我看看从哪一步开始对你更有用。
- **产品承接**：[产品名] 是 [周期/形式]，主要内容是 [做什么]，适不适合先聊清楚。
- **边界说明**：[我们能做什么、不做什么]；不合适不会硬推。
- **品牌收尾**：没有经用户确认的品牌句，就不使用任何品牌口号，正常收尾即可。
