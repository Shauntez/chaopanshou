# 选题会与选题评分

> 建档之后，每次陪跑的第一件事就是选题。人拍板，AI 出候选，但候选必须先过一遍评分才能拿出来。

## 一、会前必做三项

1. **读画像卡**：定位、受众、红线、长期记忆（尤其"踩过的坑"）
2. **看近期热点**：当天/本周本行业热点、平台趋势、对标新爆款（要真搜，搜不到就说搜不到）
3. **看评论区**：自己号与同行号评论区反复出现的问题

## 二、候选怎么出（3–5 个，不多给）

每个候选必须带六项：

| 字段 | 要求 |
|---|---|
| 角度 | 一句话说清从哪儿切入 |
| 目标人群 | 对应画像卡 ③ 的哪一类 |
| 钩子标题 | 能直接用的标题，不是"关于 X 的思考" |
| 内容类型 | 案例复盘 / 方法干货 / 观点人设 / 机会解读 |
| 预期作用 | 破圈 / 立信任 / 引流 / 转化，只说一个 |
| 素材来源 | 来自哪个热点、哪条评论、哪段真实经历 |

**不许凑数**：三个好过五个烂。今天热点不对口，就明说只能出 3 个。

## 三、七维评分（自己先过一遍再给他）

每个候选逐维打 1–10 分，写清依据，不许凭感觉：

| 维度 | 评什么 | 高分含义 |
|---|---|---|
| 流量潜力 | 痛感强度 + 平台话题热度 + 有没有人搜 | 有自然需求 |
| 账号匹配 | 与定位、受众、已有内容体系的契合度 | 不跑偏 |
| 竞争差异化 | 同类饱和度 + 能否切出新角度 | 竞争低 |
| 时效价值 | 常青还是蹭一次性热点 | 常青 |
| 变现空间 | 能不能自然接到转化动作 | 能 |
| 制作成本（反向） | 素材、设备、时间门槛 | 好拍 |
| 合规风险（反向） | 敏感领域踩线可能 | 安全 |

**综合判断**（按上面的重要性加权，满分 100）：

- **≥ 70**：做，排期
- **50–69**：改方向，必须附至少 2 条优化建议（换角度／换形式／换时机）
- **< 50**：不做，必须附至少 2 个替代选题

任一维度低于 3 分，直接淘汰，不要拿出来讨论。

## 四、讨论方式

- 逐个说，不一次性甩表格让他自己挑
- 每个候选给一句"我为什么推荐它"，一句"它的问题在哪"
- 他说"都不行"时，先问清是方向不对还是表达不对，再重出；不许换个词重发一遍
- 拍板后立刻进 `script.md` 出稿

## 五、选题台账

```markdown
| 序号 | 选题 | 类型 | 钩子 | 状态 | 数据 | 复盘结论 |
|---|---|---|---|---|---|---|
```

状态：候选 / 已拍板 / 已出稿 / 已发布 / 已复盘。低效选题必须标注原因，避免重复。
