# 矩阵操盘规则

> 多人一起做号时，先跑通一个人，再复制到下一位。产品分层与分润规则由团队自己定，AI 不替团队拍板。

## 一、差异化原则

- 每人一份独立画像卡，定位互不重叠；同一团队内避免人设、人群、选题撞车
- 差异化来源：过往行业、专长方向、性格表达、出镜形式、目标人群分层
- 主号立品牌与信任，成员号承接细分人群与场景；方法论可复用，**故事和案例必须是本人真实经历**

## 二、内容分工（按特长分配，不强塞）

| 号型 | 谁来做 | 讲什么 |
|---|---|---|
| 观点人设号 | 创始人 / 负责人 | 商业判断、行业机会、创业起落 |
| 方法干货号 | 专项负责人 | 可跟练的步骤、工具落地、实操过程 |
| 案例纪实号 | 交付负责人 | 客户或学员从参与到出结果的真实过程 |
| 机会解读号 | 内容负责人 | 行业趋势与落地机会，做破圈引流 |

## 三、号间互导

- 主号评论区、简介、置顶把细分人群导向对应成员号；成员号在相关话题下回流主号
- 不在视频里硬喊“关注另一个号”，用“同类问题那个号讲得更细”承接
- 线下活动可多号同框纪实，互相导流

## 四、产品分层与承接

- 前端引流（低客单体验）→ 中端培育 → 后端高客单/企业服务，各号按自身人群引导到对应层级
- 线索归属与分工由团队内部约定；AI 只记录来源与承接路径，不定分润规则

## 五、排期与节奏

- 单人产能有限时先保稳定更新，再追数量；选题会按成员分别开
- 团队层面统一对外口径与品牌主张；各号表达风格可不同
- 定期复盘各号数据，低效方向及时调整，跑通的公式再复制给新成员

## 六、扩展顺序

1. 第一位成员：建档 → 定位卡 → 首批选题 → 出稿 → 跑通闭环
2. 沉淀可复用模板与话术
3. 再为下一位建档，复用流程，差异化定位
