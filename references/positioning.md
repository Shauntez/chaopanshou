# 定位报告

> 时机：深度访谈完成 + 对标拆解完成之后。这是第一个正式交付物，用户拿它决定后面拍什么。
> 核心判断只有一句：**我和别人不一样、且用户需要、且我能持续做到**——三者缺一，定位不成立。

## 一、先做赛道扫描（不扫就谈定位=空谈）

从对标拆解表里提炼三样东西：

- **主流打法共性**：这个赛道头部和腰部普遍在做什么（选题、形式、人设、调性）
- **同质化点**：已经烂大街、用户审美疲劳的做法——疲劳处就是机会
- **用户未被满足处**：评论区抱怨、"有没有人做 X"、反复出现的疑问

## 二、定位坐标（画一张二维图）

选**两个真能区分竞品**的维度，把对标账号摆上去：

常用维度对：专业↔娱乐｜高端↔平价｜硬核↔小白｜理性↔情感｜垂直↔泛化｜快节奏↔慢生活｜大众↔小众

看出两个区域：
- **聚集区**＝红海，别扎堆
- **空白区**＝可能的机会，但要验需求

维度选错的自检：如果所有竞品在这个维度上都差不多，这个维度没用，换一个。

## 三、空白区是真是假

| 类型 | 判断标准 |
|---|---|
| 人群空白 | 某类人没被专门服务（"给 X 人群的 Y"）——有需求即机会 |
| 场景空白 | 某场景没人切（通勤时／带娃时／开会前）——高频场景更佳 |
| 价值空白 | 同品类主打不同价值（别人讲效果你讲体验） |
| 形式空白 | 形式创新——最易被抄，必须叠加别的维度 |
| **伪空白** | 没人做是因为没需求／做不动／平台不推——直接排除 |

验证方法：这个空白处有没有搜索量、评论诉求、竞品失败的痕迹？三个信号全无，就不要押。

## 四、三象限成立性检验

| 象限 | 看什么 | 判断 |
|---|---|---|
| 我擅长 | 有证据的能力（做过什么、做成了什么） | 有证据＝成立；只有自我评价＝可疑 |
| 我喜欢 | 愿意长期讲、讲起来有劲 | 不愿意讲＝做不久 |
| 对手在做 | 对标里有没人做成、做成几个 | 无人做＝警惕伪空白；一窝蜂＝必须差异化 |

结论必须落到交集，并写明缺口在哪。只有一个圈成立时，直接说"这个定位还不成立，先做 [X] 验证"。

## 五、差异化选在哪一维（按护城河排序）

1. **人设／独特经历**（最难抄，护城河最深）
2. **人群 + 场景组合**
3. **价值主张**
4. **内容形式**（最易抄，只能当辅助）

选 1–2 个做主差异点，其余当补充。差异化壁垒写成可验证句：`因为我有 [具体经历/数字/资源]，所以 [别人做不到的那件事]`。禁用：经验丰富、资源广、懂行业、跨界能力强。

## 六、一句话定位（公式化，不许自由发挥）

```
为 [具体人群] 在 [具体场景] 提供 [独特价值] 的 [品类/角色]
```

三条硬要求：
- **具体**：人群、场景、价值要具体到能想出画面
- **可记**：一句话能复述
- **可验证**：能被内容证明，不是自封

反面：含"更好／更专业／更用心"这类空话，或"什么都做"的大而全。

## 七、内容主线（2–3 条，不给四条）

从案例复盘／方法干货／观点人设／机会解读里挑，写明占比与作用：

```markdown
| 主线 | 占比 | 作用 | 典型选题方向 |
|---|---|---|---|
| 方法干货 | 50% | 立专业、导私信 | [3 个方向] |
| 观点人设 | 30% | 攒信任、破圈 | [2 个方向] |
| 案例复盘 | 20% | 证结果、转介绍 | [2 个方向] |
```

## 八、转化路径与边界

- 转化链：`内容 → 什么动作 → 什么产品 → 什么客单`，每步标明入口
- 边界：不做的内容、不接的人群、不承诺的结果、未开展的业务。必须与画像卡 ⑤ 一致

## 九、怎么验证定位成立（给三个信号）

1. 粉丝画像是否真往目标人群聚（看评论与私信的人是谁）
2. 有没有人主动用你的定位标签描述你
3. 同类竞品能不能轻易抄走你的核心差异

三个月内一个信号都没有，说明定位需要调，不要硬扛。

## 十、报告交付要求

- 两页内，短句＋表格，不写"综上所述"
- 每条判断后面跟依据（来自访谈哪句话 / 哪个对标）
- 末尾列【待填】清单，说明缺了影响哪个判断
- 固定附**首批 3 条选题**（一条观点、一条干货、一条案例），带钩子标题与目标人群
- 用户确认后才定稿写 `定位报告_<称呼>.md`

## 十一、常见坑

- 只求"不同"忽略"有需求" → 小众自嗨
- 定位太宽 → 没有心智占位
- 差异落在形式层 → 没护城河
- 脱离自身优势硬凹 → 做不长久
- 空话定位 → 用户无感、无法验证
